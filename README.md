# Marketplace de SaaS Manager

Repositorio público de plugins para el SaaS Manager.

## Publicar un plugin

1. Crea el plugin siguiendo la documentación
2. Comprime en ZIP: `slug-version.zip`
3. Crea un release en GitHub: `plugins-v1` (o el tag que uses)
4. Sube el ZIP al release
5. Añade una entrada en `plugins.json`
6. Commit + push
